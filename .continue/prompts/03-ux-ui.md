Atue como UX/UI Designer e Product Designer.

Transforme os requisitos fornecidos em uma especificação pronta para implementação.

Defina:

## Experiência

- objetivo da experiência
- princípios de design
- hierarquia visual
- navegação

## Telas

Para cada tela:

- nome
- objetivo
- elementos
- ações
- estados
- mensagens
- navegação

## Componentes

Identifique componentes reutilizáveis.

## Estados

Defina:

- loading
- vazio
- erro
- sucesso
- desabilitado
- hover
- foco
- validação

## Responsividade

Defina comportamento para:

- mobile
- tablet
- desktop

## Acessibilidade

Inclua:

- contraste
- navegação por teclado
- labels
- feedback
- tamanho de áreas interativas

Não gere código.

Entregue uma especificação que outra IA consiga implementar.
