# TSD — Product Requirements Document

## Visão

O TSD — Tempo a Sós com Deus é um aplicativo para auxiliar o usuário a organizar e acompanhar sua rotina devocional.

## Problema

O usuário pode ter dificuldade para manter consistência e visualizar seu histórico de momentos de:

- leitura bíblica;
- oração;
- jejum;
- devocional.

## Solução

O TSD centraliza esses registros em uma experiência simples e mobile-first.

## Funcionalidades principais

### Leitura bíblica

- livros;
- capítulos;
- registro de leitura;
- progresso;
- histórico.

### Oração

- iniciar oração;
- registrar duração;
- histórico;
- estatísticas.

### Jejum

- registrar jejum;
- duração;
- histórico;
- estatísticas.

### Devocional

- registrar devocional;
- referência bíblica;
- histórico.

### Jornada

Sistema para organizar objetivos e práticas espirituais.

### Grupos

- criar grupo;
- entrar;
- convite;
- participantes;
- progresso coletivo.

## Princípios

O TSD deve ser:

- simples;
- acolhedor;
- espiritual;
- privado;
- seguro;
- mobile-first.
